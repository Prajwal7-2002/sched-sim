FCFS Head-of-Line (HOL) Blocking Analysis

In standard continuous batching FCFS, when Request #1 arrives with a 2,048-token prompt, its prefill phase consumes the full GPU compute budget for 120ms. During this entire prefill burst, ongoing decoding requests (Req #2, #3, #4) cannot generate any tokens, causing their inter-token latency (TPOT) to explode from 25ms to over 140ms.

Python SDK & CLI Usage
Run discrete-event serving simulations from terminal or Python scripts
Installation:
pip install sched-sim
Run Serving Simulation CLI:
# Run Sarathi Chunked Prefill simulation on RAG traces sched-sim run --scheduler chunked --chunk-budget 512 --trace traces/rag_workload.json # Compare continuous batching vs SJF sched-sim compare --schedulers fcfs,sjf,chunked,disaggregated --output results.json
Python API Integration:
from sched_sim.core.engine import EventEngine from sched_sim.schedulers.chunked import ChunkedPrefillScheduler from sched_sim.hardware.gpu import GPUProfile # Configure hardware profile and scheduler gpu = GPUProfile.from_preset("rtx_4090") scheduler = ChunkedPrefillScheduler(chunk_budget_tokens=512) engine = EventEngine(hardware=gpu, scheduler=scheduler) results = engine.simulate(trace_path="traces/lmsys_sample.json") print(f"Throughput: {results.throughput_tok_per_s:.1f} tok/s") print(f"TTFT P99: {results.ttft_p99_ms:.1f} ms | TPOT P99: {results.tpot_p99_ms:.1f} ms")
