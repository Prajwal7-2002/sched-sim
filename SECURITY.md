---

## Reporting a Vulnerability

If you discover a security vulnerability in `sched-sim`:

* **Please DO NOT file a public issue.**
* Report the issue privately through [GitHub's Private Vulnerability Reporting](https://github.com/Prajwal7-2002/sched-sim/security/advisories/new) or by emailing maintainer Prajwal Pujari at `prajwalpujari16@gmail.com`.

### Submission Details
Please include:
1. Description of the vulnerability or flaw.
2. Steps to reproduce or proof-of-concept simulation code.
3. Potential impact on the host system or simulation integrity.

You will receive an acknowledgment within 48 hours, followed by coordinated disclosure and patch updates.
